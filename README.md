# Homebrew tap for anki-x

```sh
brew install HunterChan-SR/tap/anki-x
anki-x
```

The formula is published by [anki-x](https://github.com/HunterChan-SR/anki-x)'s
release workflow after native builds and installation checks pass. It uses the
release's self-contained runtime and pinned SHA-256 values; Python is not needed.

Supports macOS 13+ on Apple Silicon/Intel and Linux x86_64 with glibc 2.35+.
Current versions are unsigned prereleases. The first-run setup helps connect
Anki Desktop and its add-on. User settings and Anki data stay outside Homebrew.

Update with `brew upgrade HunterChan-SR/tap/anki-x` and remove the program with
`brew uninstall anki-x`. To report a problem, use
[anki-x Issues](https://github.com/HunterChan-SR/anki-x/issues).

Formula updates are generated in the main project. Do not edit checksums here.
This tap is independent of Homebrew core.
